# Frontend Mentor - Time tracking dashboard

This is my solution to the ![Design preview for the Time tracking dashboard coding challenge](./preview.jpg) challenge from Frontend Mentor. The main goal was to replicate the provided design and add interactivity using HTML, CSS, and plain JavaScript.

## 📋 Challenge Overview

Users should be able to:

- View the optimal layout for the site depending on their device's screen size.
- See hover states for all interactive elements on the page.
- Switch between daily, weekly, and monthly statistics.

## 🛠️ Built With

- Semantic HTML5
- CSS3 with custom properties
- Flexbox and CSS Grid
- JavaScript (ES6+)
- Mobile-first design

## 🧠 What I Learned

- How to implement smooth and interactive hover behaviors that dynamically update the active state using plain JavaScript.
- How small CSS adjustments like margins can cause unintended layout shifts and how to fix them for stable layouts.
- How to manage the active state of UI elements to ensure a smooth and predictable user experience.

## 🧩 Challenges Faced

- Refining the JavaScript logic to store the last hovered element as active, ensuring the correct state persisted after mouse exit.
- Keeping the layout stable while applying interactive CSS effects that may alter the positioning of elements.

## 📈 Areas for Improvement

- Improving how CSS interactions affect layout stability, especially when visually differentiating active elements.
- Exploring more scalable patterns in plain JavaScript to manage interactive UI state without relying on frameworks.
